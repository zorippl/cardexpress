# CardExpress

本地运行的 RAW / JPG 照片归档桌面工具，macOS 优先，同时提供 Windows 打包配置。

## 功能

- 选择存储卡 / 文件夹，递归扫描当前格式。默认 RAW ONLY，也可切换为 JPG ONLY（含 `.jpg` / `.jpeg`，不区分大小写）。切换会清空选区并重新扫描，不混合归档不同格式；隐藏目录始终忽略。
- 支持索尼 ARW、佳能 CR2/CR3、尼康 NEF/NRW、哈苏 3FR/FFF，以及 DNG、RAF、ORF、RW2 等。
- 使用 ExifTool 读取 `DateTimeOriginal`，缺失时尝试照片元数据中的 `CreateDate`。不使用文件修改时间，不将拍摄时间转换为 UTC。
- 日期扫描查询拍摄日期、相机字段以及可用的内嵌预览，最多并行读取 4 个文件；快速读取没找到有效拍摄日期时，会再尝试常规读取。扫描期间分批显示已识别的照片，可先浏览和预览，扫描结束后再选片和归档。
- 同一天的照片在同一滚动区连续平铺，不分页；滚动到可见区域才加载缩略图。点击照片在应用内查看大图，左右方向键切换同一天的照片，Esc 关闭。
- 用「− / ＋」调整缩略图密度，或切换到文件名列表查看拍摄日期、时间和大小；两种模式共享勾选状态。
- 单张勾选、当天全选/清空、所有日期全选/清空均可使用。Shift + 点击勾选框可选取或取消连续区间；也可用当天序号（如 `1-10, 15, 20-25`）批量勾选或取消。在浏览区用 `⌘A` 全选当天、`⌘Shift+A` 清空当天（Windows 用 Ctrl）。
- RAW 模式优先读取 RAW 内嵌的 JPEG，提取不到时 macOS 版尝试用系统预览，不需要卡里的独立 JPG。JPG 模式则从独立 JPG/JPEG 文件生成预览。预览失败仍可按拍摄日期归档。
- 日期无法识别的文件单独展示，不自动归档。RAW 文件扩展名支持不代表每一种相机型号的元数据都已实机验证。
- 多选拍摄日，填写地点、主题、模特，生成 `20260504_上海浦东_万圣夜主题_小西`。
- 保留原文件名；同名文件自动添加 ` (1)`、` (2)`，不覆盖已有文件。重复归档也会产生编号副本，当前不自动去重。
- 只复制，不删除源文件。每个文件复制后做 SHA-256 校验，展示成功/失败结果。
- 支持停止扫描或归档。归档停止会等当前文件复制并校验完成。
- 存储卡或目标盘断开、目录不可访问时，页面会清除失效路径并提示重新选择。来源失效会清空照片和选片；只有目标失效时保留选片。受影响的任务会在当前文件处理返回后停止，不会继续复制下一张。
- 不上传照片，无远程服务、账户或云端 API。

## 本地开发

需要 Node.js **22.12 或更高版本**和 npm。不需要 Rust。

```bash
npm install
npm run dev
```

ExifTool 由 `exiftool-vendored` 依赖提供。Windows 使用随包的可执行程序；macOS/Linux 仍需系统可用的 Perl（可用 `perl -v` 检查）。首次依赖安装需联网。

仅预览界面：

```bash
npx vite --host 127.0.0.1
```

浏览器预览不具备桌面文件系统能力。选择存储卡、扫描及复制请使用 Electron 应用。

## 测试和构建

```bash
npm test
npm run build
npm start
```

`npm test` 使用临时文件测试归档规则与安全策略，并通过合成 XMP 验证内置 ExifTool 的真实读取。不需要真实 RAW；真实相机元数据兼容性仍需用实际样片验证。

## 打包

在 Mac 上：

```bash
npm run dist:mac
```

在 Windows 上：

```bash
npm run dist:win
```

在 Linux 上交叉打包 Mac 测试版（分别生成 Apple 芯片和 Intel ZIP）：

```bash
npm run dist:mac:zip
```

这里的“交叉打包”是下载对应架构的 Electron，再组装应用资源，并不是在 Linux 编译 macOS 原生程序。本项目目前没有需要交叉编译的原生 Node 扩展。

ZIP 不包含 Apple Developer 签名、公证，也不能代替 Mac 实机测试。macOS 可能阻止未签名应用启动；Apple 芯片版本还可能需要在 Mac 上补做本地 ad-hoc 签名。请不要为测试版全局关闭 Gatekeeper。正式分发仍应在 macOS 上完成签名、公证和验证。

产物在 `release/`。macOS 的 DMG、签名、公证及 Windows 安装程序需要对应系统的实际构建验证。正式对外分发建议配置 Apple Developer 签名和公证 / Windows 代码签名；本项目没有附带证书。

## 使用

1. 选择 RAW ONLY 或 JPG ONLY，连接读卡器，点击「选择存储卡」，选择卡的根目录或 DCIM 文件夹。
2. 等待拍摄日期读取完成，勾选要归档的单张照片、按序号选范围，或在左侧勾选整个拍摄日。
3. 选择电脑或其他磁盘上的目标路径，不能选择源存储卡内的目录。
4. 选「新建归档文件夹」时，选择上一级目录并填写地点、主题和模特。选「复用已有文件夹」时，直接选择已有的归档文件夹，不用填写命名信息；多个拍摄日会合并到该文件夹，不建子目录。
5. 点击「开始归档」，核对日期、文件数量和目标路径后确认复制。
6. 等待校验完成，打开归档目录检查结果，再安全弹出存储卡。

请预留充足磁盘空间，并在任务完成前保持存储卡和目标磁盘连接。目前没有自动去重或断点续传。归档失败时可查看文件级原因；重新归档已成功的文件会生成编号副本。

## 结构

```text
electron/main.cjs       桌面窗口、目录选择和 IPC
electron/preload.cjs    受限的前后端通信接口
electron/archive.cjs    RAW / JPG 扫描、日期提取、安全复制与校验
src/main.jsx           React 界面
src/styles.css         界面样式
tests/archive.test.cjs  本地文件系统测试
```
